# Overview

**Live Project Repository:**  
https://github.com/Hamzah-20/quizzler-app

Quizzler App is a mobile quiz application built using Flutter and Dart.

The application allows users to:
- Answer multiple-choice quiz questions
- Navigate through quiz flows
- Receive immediate feedback on answers
- Track score progress dynamically
- Experience a clean and responsive mobile UI

This project demonstrates:
- Flutter mobile application development
- Stateful widget management
- Dynamic UI updates
- Quiz logic implementation
- Mobile-first interface design

# Application Workflow

```text
1. Launch Application
2. Start Quiz
3. Display Questions
4. Select Answer
5. Validate Response
6. Update Score
7. Continue Until Quiz Ends
8. Display Final Result
```

# Installation

## Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

---

## Clone Repository

```bash
git clone https://github.com/Hamzah-20/quizzler-app.git
cd quizzler-app
```

---

## Install Dependencies

```bash
flutter pub get
```

---

## Run Application

```bash
flutter run
```
